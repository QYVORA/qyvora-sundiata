# Security Policy

## Supported Versions

Only the latest tagged release receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in Sundiata, please report it privately by emailing the QYVORA OffSec team at **qyvorasec@gmail.com**. **Do not open a public GitHub issue.**

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix. Once the fix is released, we will credit the reporter (if desired) in the release notes.

## Contact

- **Website:** https://qyvora.org

- **Organisation:** QYVORA OffSec — Tamale, Ghana

## Scope

This policy covers the Sundiata source code, build pipeline, and release artifacts. Issues related to the identity directory snapshots being analyzed (e.g., weak credentials or privilege escalation paths discovered *by* Sundiata) are out of scope — those should be reported to the directory administrator.

**Note:** Sundiata analyzes offline directory files only. Credentials are redacted before output and never stored or printed. Live identity source collection is not implemented.

## Responsible Disclosure

We ask that you give us reasonable time to patch and release a fix before any public disclosure.
